# Exploratory Data Analysis (EDA)

## About the Project
This project focuses on Exploratory Data Analysis (EDA) using Python. The main goal is to understand datasets, clean data, identify patterns, and discover meaningful insights through analysis and visualization.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Activities
- Data Loading and Exploration
- Data Cleaning
- Handling Missing Values
- Removing Duplicate Records
- Statistical Analysis
- Data Visualization
- Finding Meaningful Insights

## Key Learnings
Through this project, I learned how to explore real-world datasets, handle data quality issues, create visualizations, and understand patterns in data.
